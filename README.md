# BNPL Cash Flow Tracker

The new React + TypeScript landing page and local FastAPI server are developed
alongside Streamlit. See [browser development instructions](docs/react-development.md)
and the [migration scope and import contract](docs/react-ui-migration.md).

For the public demo, see [free showcase deployment](docs/showcase-deployment.md).

A rules engine that maps BNPL installment schedules to credit card statement cycles and payment due dates.

MVP 1 focuses exclusively on the calculation engine.
